## How WebAssembly Is Connected

1. [src/algovista.cpp](C:\Users\Shubh\OneDrive\Desktop\DAA-sem 4\ALGOVISTA-APP\src\algovista.cpp) is compiled with Emscripten.
2. Emscripten generates:
   - `web/algovista.js`
   - `web/algovista.wasm`
3. [web/index.html](C:\Users\Shubh\OneDrive\Desktop\DAA-sem 4\ALGOVISTA-APP\web\index.html) loads `algovista.js`.
4. JavaScript inside `index.html` calls the exported C++ function `run_algorithm(...)`.
5. C++ returns JSON containing the visualization steps.
6. JavaScript reads that JSON and draws bars, heap trees, and AVL trees in the browser.

## How JavaScript Talks to C++

Inside [web/index.html](C:\Users\Shubh\OneDrive\Desktop\DAA-sem 4\ALGOVISTA-APP\web\index.html), JavaScript calls:

```js
const pointer = Module.ccall(
  "run_algorithm",
  "number",
  ["string", "string", "string", "number"],
  [category, algorithm, values.join(","), target]
);
```

Then it reads the returned JSON string:

```js
const jsonText = Module.UTF8ToString(pointer);
```

Then it frees the memory:

```js
Module.ccall("free_result", null, ["number"], [pointer]);
```

## VS Code Terminal Commands

Open this folder in VS Code and use the integrated terminal.

### First-time setup

If `emsdk` is not already present:

```powershell
cd "C:\Users\Shubh\OneDrive\Desktop\DAA-sem 4\ALGOVISTA-APP"
git clone https://github.com/emscripten-core/emsdk.git
.\emsdk\emsdk.bat install latest
.\emsdk\emsdk.bat activate latest
```

### Build the project

Run this every time you want to rebuild:

```powershell
cd "C:\Users\Shubh\OneDrive\Desktop\DAA-sem 4\ALGOVISTA-APP"
cmd /c "call emsdk\emsdk_env.bat && emcc src\algovista.cpp -o web\algovista.js -s WASM=1 -s EXPORTED_FUNCTIONS=[_run_algorithm,_free_result,_malloc,_free] -s EXPORTED_RUNTIME_METHODS=[ccall,UTF8ToString] -s ALLOW_MEMORY_GROWTH=1 -s ENVIRONMENT=web -std=c++17"
```

### Run the local server

Use Emscripten's built-in server helper:

```powershell
cd "C:\Users\Shubh\OneDrive\Desktop\DAA-sem 4\ALGOVISTA-APP"
cmd /c "call emsdk\emsdk_env.bat && emrun --no_browser --port 8000 web"
```

Then open:

[http://localhost:8000](http://localhost:8000)
